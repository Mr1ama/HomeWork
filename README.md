# CRUD API каталога настольных игр

Учебный API на FastAPI для просмотра, создания, обновления и удаления игр. Данные хранятся в обычном списке Python в памяти и сбрасываются после перезапуска сервера.

## Запуск

```bash
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Откройте Swagger: <http://127.0.0.1:8000/docs>.

## Модель игры

```json
{
  "id": 1,
  "title": "Каркассон",
  "genre": "Стратегия",
  "players": 5
}
```

Для создания и обновления отправляются поля `title`, `genre` и `players`. `id` назначает сервер. Созданы две модели Pydantic: `GameCreate` для входных данных и `Game` для ответа с идентификатором.

## Маршруты

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/games` | Возвращает список игр |
| POST | `/games` | Создаёт игру и возвращает статус `201` |
| PUT | `/games/{game_id}` | Полностью обновляет игру, сохраняя её ID |
| DELETE | `/games/{game_id}` | Удаляет и возвращает игру |

Если PUT или DELETE не находят игру, API возвращает статус `404` и сообщение `Игра не найдена`.

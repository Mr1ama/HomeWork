# Каталог настольных игр

CRUD API на FastAPI для просмотра, добавления, изменения и удаления настольных игр.

## Запуск

```bash
python -m venv venv
```

Активируйте виртуальное окружение, затем установите зависимости и запустите сервер:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Документация Swagger доступна по адресу <http://127.0.0.1:8000/docs>.

## Модель игры

```json
{
  "id": 1,
  "title": "Каркассон",
  "genre": "Стратегия",
  "players": 5
}
```

При создании и изменении передаются `title`, `genre` и `players`. Название и жанр должны быть непустыми, количество игроков — положительным целым числом. Идентификатор назначает сервер.

## Маршруты

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/games` | Список игр |
| POST | `/games` | Создание игры, ответ `201` |
| PUT | `/games/{game_id}` | Полная замена игры с указанным ID |
| DELETE | `/games/{game_id}` | Удаление и возврат удалённой игры |

Если игра с указанным ID отсутствует, PUT и DELETE возвращают `404` с сообщением `Игра не найдена`. Данные хранятся в памяти и сбрасываются при перезапуске сервера.

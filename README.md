# Каталог космических миссий

## Краткое описание

Консольная программа на Python для просмотра каталога космических миссий и поиска миссий по направлению.

## Возможности

- Вывод полного списка миссий с годом запуска и направлением.
- Поиск миссий по введённому направлению без учёта регистра.
- Информативное сообщение, если совпадений нет.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: вывод каталога, ввод направления и показ результатов поиска. |
| `missions.py` | Данные миссий и функции отображения и поиска. |
| `README.md` | Описание проекта и инструкция по запуску. |

## Запуск

Требуется Python 3. Запустите из каталога проекта:

```console
python main.py
```

Введите направление, например `Луна`. Поиск не учитывает регистр. Если миссии не найдены, программа сообщит об этом.

# API каталога космических станций

API на FastAPI для просмотра и добавления космических станций.

## Модели

`StationCreate` — данные, которые передаёт пользователь при создании станции:

- `name` — название станции (`str`);
- `orbit` — орбита или объект (`str`);
- `crew` — количество членов экипажа (`int`).

`Station` — данные, которые API возвращает:

- `id` — идентификатор станции (`int`);
- `name` — название станции (`str`);
- `orbit` — орбита или объект (`str`);
- `crew` — количество членов экипажа (`int`).

## Эндпоинты

| Метод | Путь       | Назначение                |
|-------|------------|---------------------------|
| GET   | `/stations` | возвращает список всех станций |
| POST  | `/stations` | создаёт новую станцию (статус 201) |

## Запуск

```bash
python -m venv venv
venv\Scripts\activate
python -m pip install fastapi uvicorn
python -m uvicorn main:app --reload
```

Swagger-документация: http://127.0.0.1:8000/docs

## Пример запроса на создание станции

`POST /stations`

```json
{
  "name": "Аврора",
  "orbit": "Марс",
  "crew": 5
}
```

Сервер сам добавит `id` и вернёт созданную станцию со статусом `201`.

Если передать неверные данные, например текст вместо числа в поле `crew`, FastAPI вернёт ошибку `422`.

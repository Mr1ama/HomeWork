# API каталога фантастических фильмов

Учебное API на FastAPI для просмотра и добавления фантастических фильмов.

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/movies` | Список фильмов |
| GET | `/movies/{movie_id}` | Получение фильма по id |
| POST | `/movies` | Добавление фильма |

## Обработка ошибок

| Ситуация | Статус-код |
|---|---:|
| Фильм найден | 200 |
| Фильм создан | 201 |
| Название уже занято | 400 |
| Фильм не найден | 404 |
| Данные не прошли проверку | 422 |

## Запуск

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите сервер из папки `science_fiction_movies_api`:

```bash
python -m uvicorn main:app --reload
```

Swagger-документация доступна по адресу `/docs`.
